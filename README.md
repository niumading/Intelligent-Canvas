# Intelligent Canvas

面向公司员工的本地 AI 创作画布。当前版本保留画布、素材管理、模型接入和短剧工具等原有功能，后续按公司流程调整。

## Windows 启动

双击 `启动服务.bat`，然后打开 `http://127.0.0.1:3000/`。生成能力需要在页面中配置自己的模型服务。`启动短剧服务.bat` 可启动短剧模块。

本目录是开发副本。在线更新已停用，后续版本由本项目维护。不要将 `API/.env`、`data/`、`assets/`、`output/` 或打包的运行环境提交到代码仓库。

## 发布前

完成公司账号和访问控制、运行测试、第三方组件许可核查及正式品牌设置后再发布或部署。
